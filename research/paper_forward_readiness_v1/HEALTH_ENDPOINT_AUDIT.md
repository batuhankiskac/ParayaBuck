# Health endpoints
/healthz is process liveness and returns 200 while HTTP serves. /readyz parses config, recognizes configured paper auto-start as trading expected, and returns 503 unless runtime.health().healthy. An auto-start error cannot yield ready. Intentional stop is control-plane ready only when auto-start is disabled. Runtime health requires running state, required workers alive, event queue age <=30 s, fresh account <=30 s, no circuit breaker and no critical scanner failure. Thus failed reconciliation/scanner, stale account, worker death and stale event queue degrade readiness. No HTTP service was launched here; stubs/tests in tests/test_health_readiness.py and tests/test_web_settings.py verify semantics.
