# Source long list

Retrieved 2026-09-22. The list is deliberately limited to sources that can cover a canonical venue or provide a necessary issuer/fund bridge.

| Source | Role | Official evidence | Disposition |
|---|---|---|---|
| NYSE Group Security Master | Cross-market daily full/delta reference snapshots for all U.S. NMS securities approved on NYSE Group platforms | [product](https://www.nyse.com/data-products/catalog/nyse-group-security-master), [v4.1 specification](https://www.nyse.com/publicdocs/nyse/data/NYSE_Group_Security_Master_Client_Specification_v4.1.pdf) | Primary lead; entitlement and vintage proof required |
| Nasdaq Daily List + Fundamental Data | Nasdaq-listed effective-dated events plus current-month daily full master | [Daily List](https://nasdaqtrader.com/Trader.aspx?id=DailyListPD), [Daily List spec](https://www.nasdaqtrader.com/content/technicalsupport/specifications/dataproducts/dlcompletespec.pdf), [Fundamental Data](https://nasdaqtrader.com/Trader.aspx?id=FD) | Serious alternative/validation component; licensed |
| Cboe BZX Listings, Distributions and Corporate Actions | BZX-primary daily full listing snapshot and event reports | [specification](https://www.cboe.com/document/tech-spec/document/technical-specifications/cboe-bzx-exchange-u.s.-listing-corporate-actions-specification), [DataShop](https://datashop.cboe.com/equities-etfs-indices) | Necessary fallback if NYSE cross-market coverage fails validation |
| SEC EDGAR ticker maps and submissions | Issuer CIK bridge and filing-time evidence | [EDGAR data access](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data) | Supplement only |
| SEC Investment Company Series/Class | Fund series/share-class identity | [Series/Class data](https://www.sec.gov/data-research/sec-markets-data/investment-company-series-class-information) | Supplement only; incomplete for closed-end and S-6 populations |
| FINRA equity masters/daily lists | OTC/ADF/ORF reference data | [FINRA OTC symbol directory](https://otce.finra.org/otce/symbol-directory) | Not required for current canonical venue set; investigate only if OTC enters scope |

Current Nasdaq symbol directories, NYSE/Cboe current symbol pages, EDGAR DEI trading symbols, issuer pages and prospectuses are corroboration or current snapshots. None alone is a complete 2016-2026 issue master.
