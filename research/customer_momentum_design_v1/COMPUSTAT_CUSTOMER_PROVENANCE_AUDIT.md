# Compustat is an intermediate source, not a raw SEC field

The [Compustat Business Information manual](https://tevgeniou.github.io/EquityRiskFactors/CompustatManualChpt5.pdf) defines customer name `CNAME`, identifier `CID`, and a `Not Reported` code when customer revenue is available but its name is not. The [Segment Customer file manual](https://volweb.utk.edu/~pdaves/Computerhelp/COMPUSTAT/Compustat_manuals/tape_07.pdf) specifies source-year/fiscal-year keys and vendor record dates. Thus the file standardizes public-source text into a historical panel; its customer ID and abbreviations are vendor representations, not SEC raw fields. Cohen–Frazzini further apply phonetic candidate matching and **manual** PERMNO assignment, dropping unresolved names ([paper pp. 1983–84](https://pages.stern.nyu.edu/~afrazzin/pdf/Economic%20Links%20and%20Predictable%20Returns%20-%20Cohen%20and%20Frazzini.pdf)).

The observed information is a combination: publicly disclosed concentrations and names where present; Compustat collection/normalization; then researchers' own entity resolution. The examined manuals do not prove that Compustat reconstructs undisclosed anonymous identities from nonpublic sources. We must neither assume it does nor assume a public EDGAR name always exists. Source equivalence requires comparison with raw filing vintages, which this campaign has not completed.
