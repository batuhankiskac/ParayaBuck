# Independent design red-team

| Challenge | Resolution |
|---|---|
| Is this conventional momentum in disguise? | It overlaps with momentum, but the rolling maximum introduces path dependence absent from V3's residual-return consensus. Original controlled evidence supports incremental content; later evidence is mixed. It is eligible for one test, not labeled independent. |
| Does the mechanism survive momentum controls? | In the seminal U.S. and several international tests, yes; in recent international evidence, no. Anchoring remains plausible rather than causal fact. |
| Is the signal split-sensitive? | Yes. Only consistently split-adjusted closes are allowed, and split/stock-dividend rows may not be reapplied. Local structural checks found zero mechanical open/close split discontinuities. |
| Would highest HIGH be noisy? | Yes. It introduces one-print extrema and three local reverse-split-adjacent extreme highs not present in closes. Highest close is frozen. |
| Does highest CLOSE diverge from literature? | It is the closest reproducible interpretation of the papers' observed price/closing-price series and is explicit in large-firm work. The deviation from an intraday-high convention is documented, not outcome-selected. |
| Is weekly cadence unjustified? | Yes. The core literature forms monthly portfolios and the reference changes slowly. Monthly is frozen; no cadence sweep is allowed. |
| Does monthly cadence impair comparison with weekly V3? | It changes turnover and responsiveness, but that is part of the hypothesis. Shared data/capital/execution and explicit turnover/cost gates preserve a fair scarce-slot displacement test. |
| Does broad `US_EQUITY` contaminate the mechanism? | Potentially. ETFs/ETNs and other products cannot be fully excluded historically. The limitation is shared by A and B and must be disclosed; reserved roles still fail closed. It weakens external validity but is not solved here. |
| Does the unresolved security master invalidate the experiment? | Not by itself under the canonical shared contract, but ambiguous individual lifecycle identities must fail closed and results cannot be described as common-stock-only. |
| Could the effect depend on microcaps/illiquidity? | Evidence is mixed: liquid Australian stocks show raw effects but costs erase significance; large-U.S.-stock evidence is weak. The unchanged scanner and strong cost/turnover gates are mandatory. |
| Does equal weighting introduce risk differences? | Yes, intentionally and transparently. It isolates the rank signal while fixed caps, equal capital, shared slots, and drawdown gates bound the comparison. |
| Would inverse-vol weighting import too much V3? | Yes. It would conflate the reference-price hypothesis with V3-adjacent sizing and is excluded. |
| Was any choice selected for expected performance? | No local outcome was viewed. Choices follow literature construction, path interpretation, data robustness, account constraints, and causal execution. |
| Is the long-only extrapolation supported? | Only conditionally. Original evidence is mostly long-short and the short leg is important. This motivates strict displacement gates and forbids a READY verdict while execution/data prerequisites are absent. |
| Can the current generic engine run the frozen test honestly? | No. Loader normalization, month-end scheduling, broad-pool decision-bar ranking, lifetime loading, and all-in fee scaling require tested research-only support first. |

## Red-team conclusion

The signal definition survives as one defensible hypothesis, but current data
normalization and execution semantics do not yet support an honest frozen
economic run. The correct decision is blocked, not rejected and not ready.

## No-economic-peek verification

This campaign performed only:

- documentation and source-path inspection;
- external literature review;
- hashes, schemas, row/field validity, timestamps, history lengths, lifecycle
  joins, and split/corporate-action structural counts; and
- pre-outcome protocol and gate design.

It did **not** compute or inspect candidate returns, future returns, P&L, NAV,
CAGR, Sharpe, Sortino, Calmar, drawdown, profit factor, hit rate, rank IC,
top-minus-bottom or bucket returns, a parameter grid, or local candidate-vs-V3
correlation. No backtest command was run and no archived/hidden candidate
result was opened.
