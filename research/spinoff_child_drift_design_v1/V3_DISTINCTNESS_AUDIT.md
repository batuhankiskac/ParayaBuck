# V3 distinctness audit

**Provisional information-source classification: `INFORMATIONALLY_DISTINCT`.** This is a design-level classification, conditional on building a verified child event and security map. It says nothing about incremental portfolio returns or realized overlap.

V3 is a weekly, price-history strategy: its production contract first requires positive 12−1 residual momentum, then ranks 6/9/12-month residual-momentum percentile consensus. The configured formation, skip, and beta windows are 252, 21, and 273 daily bars, respectively. The inherited `minimum_history_bars` is beta-window plus one, or **274 bars for each symbol**. A genuinely new child ordinary share with fewer than 274 own daily bars cannot receive a V3 candidate score. Once it accumulates 274 bars, V3 may consider it if all other universe, scoring, and risk gates pass. The scanner's shorter historical requirements do not override this strategy requirement. [Source: `src/parayabuck/portfolio/equity_residual_momentum_v3.py:1-24,148-175`; `src/parayabuck/portfolio/equity_residual_momentum.py:88-89,196-212`; `docs/research/canonical_v3_baseline.md`.]

An issuer-specific distribution notice, child registration, and regular-way listing date would be organizational event information rather than V3's price-momentum signal. This supports informational distinctness **if** the child security is established point in time from filings and public listing evidence. The canonical bars and entity-lifetime file alone cannot distinguish a spin-off child from another new listing, nor prove the child's own history began at separation. A seasoned listed carve-out later distributed to parent owners might already have 274 bars and overlap V3 at the event date; it must not be counted as automatically distinct. [Source: `data/historical/equity_entity_lifetimes_full_v5.csv` header; `docs/research/equity_universe_limitations.md`.]

The unresolved historical `US_EQUITY` taxonomy remains binding. Any child event requires issuer-linked proof of the exact ordinary share class and historical entity interval. CIK-only or current-ticker matching is insufficient. The existing canonical files have no parent-child event link or share-class proof. Therefore actual V3 overlap counts, first eligibility dates, and portfolio complementarity remain **unmeasured**. No V3 returns, candidate returns, or return correlation were inspected.
