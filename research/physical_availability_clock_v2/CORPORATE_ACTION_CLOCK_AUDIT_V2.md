# Equity corporate-action clock

The pinned v5 action file and existing loader keep split-adjusted price semantics: noncash split rows are not reapplied as additional quantity changes. Cash-dividend rows carry `ex_date` labels. The physical scheduler maps a session ex-date to that XNYS open; if the source ex-date is not a trading session (for example 2017-05-29), it queues the action to the next valid session open, matching the canonical event loop's first subsequent execution cycle. It credits only inventory held before that open and applies the action before any opening sell/buy fill. It does not credit a prior session's close merely because that prior signal becomes available then. Terminal lifecycle liquidation is placed at the physical close of the entity's last observed session, preserving the existing close price and fee policy.

The loader yields 141,751 cash actions; five rows have non-session ex-dates (2017-05-29 or 2019-11-28). The scheduler retains canonical amounts and quantity rules. Its audit requires cash and position reconciliation and separate corporate-action event timestamps. The source lacks an independent payable-date cash ledger; this study preserves the established ex-date accounting model and does not claim broker cash settlement parity.
