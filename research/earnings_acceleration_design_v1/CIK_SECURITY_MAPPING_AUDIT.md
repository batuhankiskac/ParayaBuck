# CIK to security mapping audit

Current canonical v5 entity lifetimes (`data/historical/equity_entity_lifetimes_full_v5.csv`) contain stable entity/provider identifiers, symbol intervals, exchange, rename chain and PIT quality; they contain no CIK field. The existing corporate-action manifest helps with splits and terminal behavior, but neither file alone proves historical CIK-to-share-class identity. SEC's current ticker/CIK map is periodically updated and not guaranteed accurate or complete ([SEC FAQ](https://www.sec.gov/about/webmaster-frequently-asked-questions)); retrospective current ticker join is prohibited by the [repository public-data policy](../../docs/research/public_data_research_policy_v1.md).

A verified bridge must have dated evidence for CIK, listed share class, exchange, issuer report status, provider asset/entity ID, and canonical interval. Multiple classes need distinct security IDs; mergers/spin-offs require dated successor links; delisted issuers stay in scope historically; ADRs, foreign issuers, SPAC shells, ETFs and funds require explicit exclusion or justified class. Unknown bridge fails closed. The 14 cached CIKs were not joined to canonical securities, so mapped-event coverage and V3 overlap are unavailable.
