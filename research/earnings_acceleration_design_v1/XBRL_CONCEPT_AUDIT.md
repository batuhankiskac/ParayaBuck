# XBRL concept audit

The paper's numerator is Compustat `IBQ`, divided by split-adjusted `CSHOQ`, per [author Table 1](https://www.naaim.org/wp-content/uploads/2018/05/2018_00M_Earnings-Acceleration-and-Stock-Returns_NAAIM-Submission-with-title-page.pdf). There is no approved hierarchy from this pair to SEC concepts. `NetIncomeLoss`, `EarningsPerShareBasic`, `EarningsPerShareDiluted`, and income-from-continuing-operations tags can differ through preferred dividends, discontinued operations, noncontrolling interest, weighted-average versus period-end shares, and extraordinary-item conventions. [FASB taxonomy FAQ](https://xbrl.fasb.org/resources/taxonomyfaq.pdf) separately lists basic EPS and continuing-operations per-basic-share tags, confirming semantic separation.

Company Facts exposes only standard entity-wide facts ([SEC API docs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)); custom tags and dimensional contexts require raw filing XBRL. In the cached 14-issuer diagnostic, same-accession standard earnings coverage for visible Item 2.02 rows is zero. This does not quantify custom-only cases; those require raw exhibits. `EarningsPerShareBasic` observed on 10-Q is diagnostic only, never a substituted paper signal. Historical concept hierarchy and exact IBQ equivalence remain unproved.

Context validation for any future implementation: accession must match source; unit must be compatible; fiscal dates and duration must denote a discrete quarter; 9-month YTD cannot be Q3; duplicate facts must resolve only by a documented same-vintage rule; amended facts must not overwrite earlier decisions. No XBRL computation is approved here.
