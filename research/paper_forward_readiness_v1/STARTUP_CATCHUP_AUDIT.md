# Startup catch-up
After reconciliation, warmup, fresh account fetch and persisted rebalance resume, EngineRuntime._run_startup_catch_up invokes each portfolio runtime on the latest completed warmup bar, crypto first. It passes the same account snapshot and accumulates ordered BUY position keys across markets. A mid-cycle start may therefore create a real target/order immediately. Deterministic decision/client IDs and persisted rebalance state suppress duplicates after restart.
