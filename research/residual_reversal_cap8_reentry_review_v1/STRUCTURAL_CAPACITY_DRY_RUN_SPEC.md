# Structural capacity diagnostic and missing replay

`target_demand_diagnostic.py` reads the archived corrected 1x **target attribution only** and the current corrected causal crypto target decisions. It never reads NAV, returns, fills, prices, or P&L. It writes 495 rows of requested identities, unique slot demand, overlap, admitted target exposure, and source count denials for cap 6 and cap 8. The executable comparison is a **target-demand diagnostic**, not an accepted current physical shared-account replay.

For each archived equity weekly label, the script uses the last isolated crypto decision timestamp at or before that label. It lets crypto target names claim up to two slots first, then admits V3 and reversal names in their original source ranks. The next source is the one with the lower accepted/requested exposure fraction; V3 wins exact ties. An overlapping equity symbol uses one account slot and retains both source contributions. Each source's rejected contribution remains cash. This rule is deterministic and independent of alpha outcomes. It is a proposed research-only arbitration, not current production behavior.

The diagnostic cannot claim current physical capacity because archived equity labels predate the physical availability clock, crypto hysteresis was generated from isolated holdings rather than shared-account holdings, and it has no synchronized working orders, pending openings, SELL completion, gross/cash state, or re-plan state. Current `physical_availability_clock_v2/shared_replay.py` permits one engine per market, so V3 plus reversal cannot be run there without a research-only multi-source extension. Current runtime counts positions, working orders, and pending reservations; an intended SELL frees a slot only after a fresh zero-position observation. These are decisive missing inputs for a faithful dry run.

The required repair is a research-only no-return replay with physical XNYS completed-close decisions and next eligible open, corrected causal crypto hourly fills, current crypto 96-hour hysteresis recomputed from shared-account holdings, pending and working reservations, SELL-before-BUY/re-plan chronology, current gross/cash/name-cap checks, and per-source attribution. Freeze the arbitration contract before producing that replay. No economic fields may be loaded or written. Only after its candidate-specific cap6/cap8 counts and exposure are verified may materiality be decided.
