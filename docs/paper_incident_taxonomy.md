# PAPER incident taxonomy

**Mode:** `paper`, equity only (`equity_leveraged_trend_v1`), **LIVE disabled**. No generic `runtime error` bucket.

Every incident defines severity, halt, retry, recovery, operator action, telemetry payload.

---

## Taxonomy (12 categories, `monitoring/incident.py` `IncidentCategory`)

| # | Category | Severity | Trading Halts? | Auto-Retry | Recovery Condition | Operator Action | Telemetry Payload |
|---|----------|----------|----------------|------------|--------------------|-----------------|-------------------|
| 1 | **PROVIDER_UNAVAILABLE** (Alpaca 5xx/429/timeout) | `warning` → `critical` after 5 attempts | No global halt; entries gated if account/signal path | Exponential `2^(n-1)` ≤16s, `n≤5` streams; reconcile 60s next cycle; startup `TransientStartupError` | `broker.reconcile()` success + fresh account + `health.healthy` | `incident_id, timestamp, category, severity, account_id, provider, http_status, retry_attempt, error, duration_ms` |
| 2 | **BROKER_ACCOUNT_STALE** (`age >30s`) | `critical` | **Yes — all decisions, SELLs included.** The account snapshot is re-queued for a bounded retry (`engine.decision_retry_window_minutes` after the close), so a short outage costs latency, not the session | `pb-account` 15s poll indefinitely | Fresh snapshot ≤30s + reconcile clean | Check broker/clock, no reset needed (self-clears) | `incident_id, timestamp, account_id, last_account_at, age_seconds, threshold, consecutive_failures` |
| 3 | **POSITION_DRIFT** (broker qty ≠ ledger) | `critical` | **Yes global halt** `ownership_drift` `safety_incidents` survives restart | **No auto-retry** | `broker.reconcile()` no drift + `reset_safety_lock` | Inspect `PaperIncidentReport.external_position_symbols`, manual reconcile, `reset_safety_lock` | `incident_id, symbol, broker_qty, ledger_qty, delta, positions_snapshot` |
| 4 | **ORDER_DRIFT** (missing local/broker, manual exits) | `critical` if protection broken else `degraded` | Global halt if `protection_failure`, else degraded | Single `_schedule_reconcile` coalesced + 60s periodic. TRANSIENT (network-class) failures block entries but only the `engine.reconcile_failure_threshold`-th consecutive one raises `reconciliation_failed` / `reconciliation_bug_suspected`; drift/ownership/protection failures halt immediately | `reconcile()` success clears `safety_incidents` + fresh `last_reconciliation_at` | `reconcile_paper_incident.py`, `reset_safety_lock` if halted | `broker_orders_missing_locally[], local_orders_missing_at_broker[], manual_exit_order_ids[], equity_residual, consecutive_failures` |
| 5 | **PENDING_ORDER_UNKNOWN** (`working`/`pending` non-terminal, `AmbiguousOrderState`) | `critical` | **Yes market halt** `rebalance_reconciliation_required` | **No blind retry**, only `reconcile()` next cycle; BUY deferred until SELLs terminal | All SELLs terminal via `is_terminal_order_status` + `get_order_by_client_id` verified; `advance_rebalance()` → `buy_ready` | Wait for broker finality, `_verify_market_halts`, `reset_safety_lock` | `incident_id, market, decision_id, client_order_id, status, pending_seconds` |
| 6 | **SIGNAL_HISTORY_UNVERIFIED** (splits not authoritative) | `warning` | **Yes equity entries and exits held** (`signal_adjustment_unverified`: no BUY and no SELL) | Hourly `pb-signal-adjustment` 3600s + per-decision latch; no intra-call retry, deduped alerts | `healthy==true` + `verified_through_by_symbol≥decision_timestamp` + `last_success≤3600s` | Wait for provider `adequate_coverage`, check digest/universe | `incident_id, market=equity, inadequate_symbols[], required_oldest_by_symbol{}, verified_through_by_symbol{}, last_error` |
| 7 | **DATABASE_ERROR** (SQLite OperationalError/Busy/disk WAL) | `critical` if write, else degraded | **Yes fail-closed** on write (3 generic fails → `bug_suspected` halt) | Read `mode=ro busy_timeout=5000` retry, write single immediate then escalate | Write `COMMIT` + `PRAGMA integrity_check==ok`; read `_table_exists` | Check disk/permissions, `backup.verify_backup`, restore WAL snapshot | `incident_id, db_path, table, sql, sqlite_code, consecutive_failures` |
| 8 | **STATE_RESTORE_FAILED** (corrupt `risk_state`, `safety_incidents`, `PortfolioState` v3) | `critical` if persistent incident lost else `warning` | Yes if `PERSISTENT_INCIDENT` corrupt, else no | No auto-retry (startup deterministic), backfill `INSERT OR IGNORE` idempotent | Load succeeds `load_safety_incidents` + `load_risk_state` parsable, schema v3 valid | Restore `backup_database`, `reset_safety_lock` after reconcile | `incident_id, table, row_id, schema_version, corrupt_field, error` |
| 9 | **DUPLICATE_DECISION** (same `decision_timestamp+market+digest`) | `warning` | **No halt** (idempotent skip) | No retry, dedup filter | Single canonical decision persisted, `UNIQUE(account_id,configuration_digest,decision_timestamp,market)` holds | Verify `portfolio_decisions` count == periods | `incident_id, market, decision_timestamp, strategy_name/version, existing_decision_id, duplicate_count` |
| 10 | **DUPLICATE_ORDER_RISK** (same `client_order_id` would submit twice) | `critical` | **Yes blocked** fail-closed | No blind re-submit, deterministic `IdempotencyKeyFactory` + `UNIQUE idx_orders_broker_id` + `get_order_by_client_id` pre-check | Broker dedup single fill stream or `open_orders` terminal; `portfolio_orders` PK prevents double-insert | Verify timezone-aware key, audit `duplicate_client_order_ids` | `incident_id, client_order_id, decision_id, symbol, side, rebalance_number, broker_order_id` |
| 11 | **CLOCK_OR_SESSION_MISMATCH** (host skew, `queue_age>30s`, `is_regular_equity_time`) | `warning` → `critical` if persists | Yes entries gated `event_queue_stale` | Bounded (`data_finalization_grace_seconds` is 2, but the close-flush floor of 30 s is the effective bound; `Buffer STALE_REJECTED`) | `host_time` vs broker `Bar.timestamp` within tolerance + `queue_age≤threshold` | Sync NTP, verify `NEW_YORK` tz, restart if `has_data_gaps` | `incident_id, market, symbol, timeframe, bar_timestamp, queue_age_seconds, threshold, host_time_iso, broker_time_iso` |
| 12 | **RESTART_RECOVERY_FAILED** (`safety_incident` not cleared, `runtime_sessions` unended, two-phase stuck) | `critical` | **Yes halt persists** until verified recovery | No unbounded retry; `restart_count>5` halt, `reconcile` 60s loop continues but not clear without proof | `broker.reconcile()` success + `clear_safety_incident` single-reason + `_verify_market_halts` + `runtime_sessions.ended_at` + `rebalance complete` | `reset_safety_lock` for recoverable reasons, `start_new_risk_epoch` for drawdown | `incident_id, circuit_breaker_reason, safety_incidents_active[], runtime_sessions{total,unended,restart_count}, rebalance_execution{decision_id,phase,status}, high_water` |

**Standard payload for all:** `incident_id` (uuid4), `timestamp` UTC iso, `category` (12), `severity` (info/warning/critical), `account_id`, `market`, `retry_attempt`/`next_retry_at`, `error`/`reason`, `recovery_condition_met`, `trading_halted`, `scope`. Delivery via `alerts.emit` throttled 60s + `metrics.record_event` + `safety_incidents` persisted for halt-class. `PaperIncidentReconciler` remains read-only audit.

**No generic bucket:** every known failure above maps to one of 12; otherwise `DATABASE_ERROR` or `PROVIDER_UNAVAILABLE` as fallback, never silent.
