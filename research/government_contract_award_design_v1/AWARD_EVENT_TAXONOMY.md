# Award event taxonomy

| Type | Required treatment before economics |
|---|---|
| Initial definitive contract | Candidate only if paper semantics, public time and new demand are established |
| Undefinitized initial action | Retain not-to-exceed, obligation and later definitization separately |
| Modification / ceiling increase | Existing contract change; never label automatically as new award |
| Option exercise / incremental funding | Existing anticipated or funded work; classify separately |
| Task or delivery order | New order under existing vehicle, distinct from vehicle ceiling |
| Single or multiple-award IDIQ vehicle | Ceiling is purchasing capacity; do not count as realized revenue |
| Multiwinner award / consortium / JV | Keep winner-specific amount unknown until allocation is proved |
| De-obligation | Negative funding correction, not positive award |
| Follow-on or incumbent renewal | Mark anticipation and prior public award links |
| Sole-source versus competed award | Retain method; surprise content may differ |
| Definitization | Link to original undefinitized action, avoid double count |

PIID + awarding agency/subtier + modification/order identifier is the proposed strong duplicate key, checked against recipient and amount. [DFARS 205.303](https://www.acquisition.gov/dfars/subpart-205.3-synopses-contract-awards) explicitly includes modifications and special IDIQ/undefinitized rules. [The 2026 Boeing ceiling increase](https://www.war.gov/News/Contracts/Contract/Article/4599224/contracts-for-sept-11-2026/) illustrates why announcement presence is not new revenue. The paper's own inclusion rules are UNKNOWN, so none of these categories is yet an authorized signal event.
