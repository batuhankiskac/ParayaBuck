# Frozen canonical crypto causal execution contract

This contract is fixed before either corrected historical replay. It applies only to isolated `crypto_low_variance_hysteresis_v1` on the existing hourly source, strategy, universe, configuration, costs, and study window.

1. A source 1h bar uses an interval-start label; its OHLCV is available no earlier than `label + 1h`. A daily 1d signal requires exactly 24 contiguous, same-symbol hours from UTC 00:00 through 23:00. Its `available_at` is `max(component label + 1h)`; incomplete days produce no daily signal.
2. The 96-hour decision block is evaluated on the daily **label**, retaining the frozen strategy cadence and PIT universe identity. Physical `decision_at` and `order_created_at` are the daily `available_at` lower bound, never the label. No order can exist before `decision_at`. Same-boundary 00:00 opening prices are excluded.
3. For a pending signal-generated order, at most one fill attempt is made per UTC day. Use the first available same-symbol source-hour bar whose start is strictly later than the current day's 00:00 availability boundary and strictly later than that order's creation. Use that hour's **OPEN** as reference price. If an early source hour is missing, choose the first later observed hour of that UTC day; if none exists, leave the order pending. Never interpolate or reuse the excluded 00:00 open. A newer target may supersede an older pending order under the existing engine rules.
4. Preserve the engine's 20-positive-**daily**-bar order-known mean volume, 10% participation cap per daily attempt, residual order behavior, sell-before-buy ordering, cash checks, 2bps slippage, 2bps full spread with half applied per side, 25bps taker fee, zero fixed commission, 0.005 rebalance band, 5% crypto sleeve, and all existing strategy/risk parameters. The fill hour's completed volume is never used for its opening fill.
5. The fixed evaluation cutoff is known before replay. A terminal liquidation instruction is created from that cutoff independently of the final daily signal. For inventory still held on the final source date, it executes at the last available same-symbol source-hour **OPEN** strictly after that date's UTC midnight and no later than the pinned source endpoint. This preserves flat terminal bookkeeping and charges canonical sell costs without pretending a post-dataset quote exists. If no eligible terminal hour exists for a held symbol, fail closed instead of fabricating a price. The final day's completed bar can mark the closing account, but no post-cutoff decision creates an unfillable order.
6. `bar_label_time`, `available_at`, `decision_at`, `order_created_at`, `source_price_event_time`, and `fill_at` remain separate in corrected evidence. Every new-order fill must satisfy `source_price_event_time > order_created_at`. Original OHLCV and input hashes are immutable.

The terminal rule and missing-hour rule are correctness choices made without observing corrected returns. These may change old fill counts, prices, NAV, and target decisions through changed holdings. Those changes are audited, not tuned away.
