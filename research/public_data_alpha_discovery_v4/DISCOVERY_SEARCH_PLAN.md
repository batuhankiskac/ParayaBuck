# Search plan, fixed after the rubric

Screen 50–75 distinct economic families across price, corporate actions, SEC filing behavior, ownership, insider/governance, clinical/regulatory, financing, operating fundamentals, legal/government, public microstructure, network, and other mechanisms. Keep any bucket near or below one quarter of the list. Search primary paper or author manuscript, a later replication/critique where available, and official public source documentation. Record `not recovered` rather than inventing methods. Published statistics may be described only as `external_published_evidence`.

For each family, first apply prior exclusion and long-only/concentration plausibility. Stage A survivors must then have exact primary method, public availability and historical identity checked before Stage B. Stage C checks official source structure and concentration/slot logic without downloading or calculating candidate future price paths. Reject or defer unresolved methods and data honestly. One paper or API failure does not stop the search.

No local future return, candidate backtest, P&L, CAR, alpha or performance statistic is permitted. An automated artifact scan will reject forbidden outcome field names; if an accidental result appears it must be quarantined before interpretation.
